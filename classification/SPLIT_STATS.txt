Stratified 80/10/10; each class contributes 10.0-10.1% of its images to test.
The classes are NOT balanced (430-462 per class, a 7.4% spread).  Fiber is the
limiting class: the repository holds 434 fiber images and 430 are used.

How the split is used by the protocol (classification/paper_protocol.py)
------------------------------------------------------------------------
  dev  = train + val = 1,606   five stratified folds; every dev image is
                               predicted exactly once out-of-fold.  The
                               primary metric is accuracy over these 1,606
                               out-of-fold predictions.
  test = 179                   held out; scored once per reported variant
                               with a Wilson 95% interval.  Never used for
                               training, early stopping or model selection.

The `val` rows are not a separate evaluation set under this protocol; the
train/val boundary inside dev is ignored and the folds are re-drawn with
StratifiedKFold(5, shuffle=True, random_state=42).

The pickle stores {train_df, val_df, test_df}: lists of dicts with keys
image_path, mask_path, category, category_id, filename, base_name.  The two
path fields are the absolute paths of the machine the split was made on and
are ignored by every script here (paths are rebuilt from category + filename;
see classification/cnt_paths.py).  splits/dataset_splits.csv is the same
partition as plain text.
